# Crypto Journal App — FARPS

A full-stack application for tracking, analyzing, and managing your **cryptocurrency trading journey**.  
Built with **FastAPI**, **React**, **PostgreSQL**, **SQLAlchemy**, and **Uvicorn**, this project serves as a modern journaling and analytics platform for traders who want **clarity, consistency, and data-driven insights**.

---

## Overview

**Crypto Journal App (FARPS)** combines the power of a real-time **FastAPI backend** and a responsive **React frontend** to give traders a personal system for:
- Recording trades and market observations  
- Reviewing emotional and technical performance  
- Analyzing trends with clean data visualizations  
- Refining strategies through reflection and statistics  

This project is part of the **FARPS (Full-stack Application Research and Project System)** initiative — focusing on **engineering precision, modular architecture, and tech-driven development**.
